# Video breakdowns

One markdown file per video watched with the `/watch` skill. Each file has two sections:

1. **Full transcript**, timestamped, from the video's caption track (or a local transcription when no captions exist).
2. **Slides and data harvested**: numbers, tables and rules read from the screen, with the timestamp each item was read at.

Naming: `YYYY-MM-DD-<channel>-<topic>.md`, where the date is the day the video was watched.

Frames and downloaded media are not stored here.
